# Assets

Generated and curated project assets live here.

## Folders

```text
assets/
  generated/
    backgrounds/
    icons/
    mockups/
    ui/
  manifests/
  prompts/
```

## Rules

- Use `image_pipeline.md` before generating or saving new assets.
- Save project-bound generated assets under `assets/generated/...`.
- Keep prompt templates and reusable prompt decisions under `assets/prompts/`.
- Register app-used assets in `assets/manifests/asset-manifest.json` once the application exists.
- Do not leave referenced assets only in Codex or temporary generation folders.
